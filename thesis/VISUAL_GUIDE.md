## User Interaction Flow

### Happy Path
```
1. User writes draft text
   ↓
2. Taps ✨ (sparkles) button in toolbar
   ↓
3. Writing Assistant opens
   ↓
4. User enters/pastes text
   ↓
5. Selects action (e.g., "Improve Writing")
   ↓
6. Taps "Generate"
   ↓
7. Sees processing indicator
   ↓
8. Result appears in "Result" section
   ↓
9. User reviews the improved text
   ↓
10. Taps "Copy Result" or uses text
```

### Quick Toolbar Path
```
1. User typing in editor
   ↓
2. Taps "AI Tools" in toolbar
   ↓
3. Selects quick action (e.g., "Improve")
   ↓
4. AI processes current text
   ↓
5. Text automatically updates in editor
   ↓
6. User continues editing
```

## Visual Design Elements

### Colors
- **Purple** (#9F7AEA): AI features, sparkles button
- **Green** (#48BB78): Model available indicator
- **Orange** (#ED8936): Model unavailable warning
- **Blue** (#4299E1): Tags, info elements

### Icons
- ✨ (sparkles): Main AI button
- 🔄 (refresh): Processing indicator
- ✅ (checkmark): Success, available
- ⚠️ (warning): Unavailable, error
- 🏷 (tag): Tags
- 📄 (document): Copy
- ✏️ (pencil): Writing
- 🎚 (sliders): Adjust tone

### Animations
- **Fade in**: Results appear smoothly
- **Spinner**: While processing
- **Streaming**: Text appears character-by-character
- **Sheet transition**: Modal presentations

## Tips for Users

### Best Results
1. **Be specific**: Clear, focused text works best
2. **Check length**: Keep under ~3000 words per request
3. **Review output**: AI suggestions may need refinement
4. **Iterate**: Try different actions for best results

### Common Actions
- **Quick improve**: Use toolbar for fast edits
- **Major revision**: Use full assistant for control
- **Batch work**: Process multiple pages sequentially
- **Tag generation**: Run on completed drafts
